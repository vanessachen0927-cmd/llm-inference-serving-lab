# DistilGPT-2 inference benchmark — Tesla T4, November 2, 2026

**Source:** Results pasted by the project owner from Google Colab. The GPU benchmark has not been independently reproduced by GitHub CI.

## Environment and model
- GPU: **NVIDIA Tesla T4**.
- PyTorch: `2.11.0+cu130`.
- Transformers: `5.22.0`.
- Model: `distilgpt2` via `TransformersBackend`, `device="cuda"`, greedy generation.
- Command: `python -m scripts.benchmark --model distilgpt2 --device cuda --repeats 5 --max-new-tokens 32`.
- One warm-up call for each batch size; five measured runs per batch; batch sizes 1, 2, 4. The benchmark synchronizes CUDA before and after timing.
- Real model generation returned text for two prompts, with 5 input tokens and 32 generated token IDs each.
- 15/15 timed runs completed and the script saved `results/inference_benchmark.csv`.

## Observed medians

| Batch size | Median wall latency (ms) | Median aggregate output tokens/s |
| ---: | ---: | ---: |
| 1 | 150.28 | 212.94 |
| 2 | 231.99 | 275.87 |
| 4 | 282.92 | 452.43 |

Batch 4 provided ~**2.12x aggregate output-token throughput** compared with batch 1, while its median **batch completion latency** was ~**1.88x** higher. This illustrates a throughput/latency trade-off rather than a universal improvement. These are not per-request time-to-first-token measurements.

## Important limitations
- In-process generation benchmark, **not HTTP service latency**, concurrent user load or production-ready throughput.
- Each request uses short fixed prompts and a maximum of 32 new tokens. Other prompts, model sizes, precisions, scheduling, and batching policies may change the results.
- The `output_tokens` metric counts generated token IDs and may include special tokens; it is not a count of printable words.
- GPU device memory, time-to-first-token (TTFT), GPU utilization, queuing, and percentile latency are **not yet measured**.
- The current API can test batching, but does **not** yet implement continuous/dynamic batching or a multi-client scheduler.
- The baseline uses a small historic Transformer model (`distilgpt2`), not a modern high-scale LLM deployment.
- This is one five-repeat run per batch size; no independent replication, confidence intervals, or version-locked reproducibility proof.
